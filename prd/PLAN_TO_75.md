## 1. 规划（1）：现有方法修改（低风险，目标 ~72%）

### 1.1 融合侧扩展（零训练成本，优先做）
- 现状：C2 线已存 round1~5.pt + best.pt 共 6 个 checkpoint，目前只导出了 best.pt 与 round4.pt 的 probs。
- 行动：导出全部 6 个 checkpoint 的 TTA probs（11-view），做 **SWA / 等权平均 / α 加权**（best 给更大权重）。
- 原理：错误模式分散在不同 round，平均更鲁棒（HANDOVER §11.5/§11.7 已验证融合 +0.5pp）。
- 变体：c2×r1×r2×r3×r4×r5×best 全平均；c2 best×round5 加权；c2×round3×c 等。
- 预期：+0.3~0.8pp → 69.3~69.7%。

### 1.2 TTA 增强（零训练成本）
- 已用 11-view（1.0/1.33 多尺度角落 + 翻转 + 轻微 ColorJitter，锁 224px）。
- 扩展：尺度 1.0/1.15/1.33/1.5 四档中心+四角+翻转；或加亮度/对比度 jitter 多次采样。
- 预期：+0.2~0.4pp。

### 1.3 自训练换去噪范式 —— 软标签 / 半监督（中等成本 ~10h，核心修改点）
- 现状 C2 是 hard drop（高置信 mismatch 直接删）；uncertain 仅 0.05 权重。
- 改为 **confidence-aware 软标签 + FixMatch 式一致性正则**：
  - 高置信伪标签 → 强监督；低置信样本 → 弱/无增强预测一致性做无监督 loss。
  - 比"一致性单信号硬剔除"更充分用 ~25k uncertain 样本，避免信息流失。
- 或软加权：mismatch 赋极低权重（0.01）但保留，避免砍掉困难真样本。
- 预期：若得当 +1~2pp → ~70%。

### 1.4 LoRA 配置微调（低成本）
- 当前 rank=8，目标层 out_proj/c_fc/c_proj（QKV 合并权重 in_proj_weight 未微调，HANDOVER §4.3 明确"暂未微调"= 未挖潜力）。
- 试 rank=16/32、alpha 调整、在 in_proj_weight 也注入 LoRA；warmup 5→8 epoch。
- 预期：+0.3~0.8pp。

**现有方法修改总上限估计 ~72%**，风险低，可立即动手。

## 2. 规划（2）：全新方案（突破天花板，~72~78%）

### X1 聚类即类别（Cluster-and-Label）★ 最值得试
1. 用当前最好模型（c2 best）提全量 103k 图 512-d 特征。
2. 有约束聚类（目标 500 类）：同 folder 初始化一簇，允许分裂/合并（克服 folder 内噪声 + folder 间重叠）。
3. 聚类结果作新伪标签重训，替代原始 folder 标签（换掉最弱监督信号）。
- 预期天花板 72~76%。风险：聚类纯度难控，需多次提交验证。

### X2 自监督 adapter 打底（合规需论证）
- 在 103k 训练图做 MAE/SimCLR 式自监督，得比 CLIP 更适配本分布的视觉编码器；在 CLIP 之上加可学习 adapter（**不替换 CLIP 权重**，合规）。
- 预期 +1~3pp。

### X3 一致性正则 baked-in
- 训练时强 augment + 约束同图不同增强预测一致，把 TTA 收益 baked 进模型。

### X4 干净判别器
- 用自训练 clean/mismatch 能力训二分类干净判别器，给全量样本打分作 sample weight，比 hard drop 更平滑。
