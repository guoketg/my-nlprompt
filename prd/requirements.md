# Contest 比赛需求文档

## 赛题来源
- 官网：www.aicomp.cn/tracks/tracks-1/3629.html
- 文档：`/root/code/NLPrompt/request.md`（原始赛道通知）

## 任务目标
在标签含噪条件下，对 CLIP ViT-B/32 进行鲁棒微调，完成 500 类细粒度图像分类。

## 数据集
- 训练集：`/root/datasets/contest/train/0000...0499/`
  - 500 个文件夹，每个约 207 张图
  - 103,218 张训练图片
  - 图片均来自网络爬取，类内包含大量无关/错误图片
- 测试集：`/root/datasets/contest/test/*.jpg`
  - 24,967 张无标签图片
  - 人工精确标注，用于线上评测

## 关键约束
1. **骨干网络**：必须使用 CLIP ViT-B/32，不得替换
2. **不得引入外部数据集**：只能使用当前阶段官方数据
3. **禁止多模型集成/投票**：单一模型 + 单一推理流程
4. **可复现性**：训练过程（包括噪声筛选）必须可被赛事方直接复现
5. **人工清洗不能作为必要前置环节**：所有清洗/筛选必须自动完成

## 标签噪声特点
- 类内图片大量来自网络爬取，非目标物种、论文截图、无关物体混杂
- `all_class_predictions.json` 中的类别名为 API 识别结果，**不可靠**，不应作为监督信号
- 没有可用的真实类别名，必须采用**纯视觉方法**

## 评价指标
Top-1 Accuracy：

```
Accuracy = 预测正确的测试样本数 / 测试样本总数
```

## 提交格式
- 文件：`pred_results.csv`
- 每行：`filename,label`
- `label` 为 4 位数字类别编号，不足前补 0（如 `0001`、`0123`）
- 打包为 `pred_results.zip` 提交

## 技术方向
- 参数高效微调（PEFT）
- 噪声标签学习
- 样本筛选与重加权
- 原型学习 / 聚类去噪
- 灾难性遗忘抑制
- 长尾分布处理（复赛/半决赛阶段）

## 当前硬件/环境
- 项目 Python：`.venv/bin/python`（torch 2.6.0+cu124，CUDA 可用）
- GPU：H200 MIG 2g.35gb
- CLIP 权重：`/root/weights/ViT-B-32.pt`（已放在快速本地盘）
- 长任务启动范式：`setsid nohup ... > log 2>&1 < /dev/null &`
